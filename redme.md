# Netflix Movies & TV Shows - Exploratory Data Analysis

## Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python. The objective is to explore the dataset, clean missing values, visualize trends, and generate meaningful business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Netflix Movies and TV Shows Dataset (Kaggle)

## Analysis Performed
- Data Cleaning
- Missing Value Treatment
- Exploratory Data Analysis
- Data Visualization
- Business Insights

## Key Insights
- Movies are more than TV Shows.
- United States produces the highest content.
- TV-MA is the most common rating.
- Content increased rapidly after 2015.
- International Movies are the most popular genre.
